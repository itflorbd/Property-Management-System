## 🌟 Key Features

1. **Auto-Sliding Hero Background & Indicator-Free Card:**
   - Smooth CSS background crossfade synchronized with the featured room card every 6 seconds.
   - **Zero Indicators (Strict Requirement):** No pagination dots, numbers, or progress bars, keeping visitors engaged with continuous fresh visual discovery without clutter.

2. **Interactive Room Details Modal (`#roomModal`):**
   - Clicking any room card opens an accessible modal popup with full-resolution imagery, bed/guest specs, pricing, and 1-click call/WhatsApp actions.

3. **1-Click Instant Bilingual Switcher (বাং / EN):**
   - Native default Bengali (`bn`) with instant toggle to English (`en`).
   - Translates navigation, headlines, amenities, room descriptions, calculator labels, and contact details seamlessly.

4. **Dynamic Stay & Tour Cost Estimator:**
   - Live interactive price calculator factoring in room category, length of stay, and optional Kaptai Lake boat tour packages (Shuvolong Waterfall, Hanging Bridge, Island hopping).
   - Generates a pre-filled WhatsApp message with exact calculation for 1-click instant confirmation.

5. **Local Hill Cuisine & Dining Showcase:**
   - Showcases authentic local delicacies: Bamboo Chicken (বাঁশের ভেতর মুরগি ভুনা), Fresh Kaptai Lake Chitol/Rui fish, and indigenous bhorta platters.

6. **Kaptai Lake Boat & Sightseeing Assistance:**
   - Direct boat charter booking guide for Shuvolong Waterfall, Hanging Bridge, Rajban Vihara, and Chakma King's Palace.

7. **Video Reels Showcase:**
   - Embedded interactive links to authentic guest video reels on Facebook.

## 🚀 How to Run Locally

### Option 1: Using Python HTTP Server
```bash

python3 -m http.server 8081
```
Open [http://localhost:8081/](http://localhost:8081/) in your web browser.

### Option 2: Using XAMPP Apache
Start Apache from your XAMPP Control Panel, then navigate to:
